# Grandyra website

Website for Grandyra Limited, a branding and communications house in Dhaka. Static HTML, CSS and JavaScript, generated by `build.py`.

- `site/` is the finished website (the review copy in this repository is built with `PREVIEW=1`, so search engines ignore it).
- Edit `build.py` and `src/`, then rebuild. Do not edit `site/*.html` by hand.
- `docs/DEPLOY.md`: production build, domain, contact form, security headers.
- `docs/TESTING.md`: accessibility, device and performance testing.
- `CLAUDE.md`: project layout and rules.
